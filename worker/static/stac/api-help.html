Indian Open Maps STAC API

Discover raster collections and download individual map sheets.

OpenAPI document · Collections · Map viewer

Search with GET or POST /stac/search. Supported parameters: collections, ids, bbox, intersects, datetime and limit. GET uses comma-separated arrays; POST uses JSON arrays. Follow the next link for further pages.

Search directly on GitHub

The published indexes are STAC GeoParquet. Clients such as iomaps and Rustac can search these files locally, then read raster assets from GitHub releases, without calling this HTTP API.

Find an index in a collection's assets.index.href, or use the geoparquet links in the raw GitHub catalog. 

uvx --from rustac==0.9.19 rustac search INDEX_URL matches.json --bbox 77.6,13.0,77.61,13.01

Replace INDEX_URL with the release Parquet URL. This searches metadata; use iomaps or GDAL to extract pixels. A Parquet URL is not an API root for clients such as PySTAC Client. The current indexes are also distinct from a linked static STAC JSON catalog.

Browser access

STAC metadata and the /cog-info and /cog-tiles/... endpoints allow any browser origin. Asset links retain their direct GitHub URLs; each file server controls CORS for its own responses. Rendered tiles are distinct from raw TIFF bytes. Successful raw-file /proxy responses omit CORS headers, so another website's JavaScript cannot read them. This is a browser restriction, not authentication.
